# 按住录音 Demo

[English](recording.md)

在 Arduino IDE 中打开 [PushToTalk](../examples/PushToTalk/PushToTalk.ino)。示例将有符号 16 位、16 kHz 单声道 PCM 存入 96 KB RAM 缓冲，不需要 PSRAM、网络、文件系统或 API 密钥；重启后录音丢失。

- 按住 OK：按键消抖后开始录音，屏幕显示 RECORDING、录音时长和输入音量条。
- 松开 OK：结束录音。持续按住超过 3 秒时自动结束；再次录音需先松开再按下。
- UP：通过板载扬声器回放录音。
- DOWN：清除已录内容，或停止回放。停止回放后，需要再次按 DOWN 才会清除录音。

麦克风初始增益为 24 dB，串口会报告削波计数；回放音量为 100%。录音结束后，示例去除直流偏置，将 RAM 中的录音峰值调整到约 20,000，最大放大 8 倍，接近静音时不放大；用于改善较弱人声的回放，并保留数字峰值余量。可按录音距离在草图中调整。115200 波特率串口日志输出采样数、音频时长、实际经过时间、峰值、RMS 和削波样本数。I/O 只完成部分传输时显示错误，不判为录音成功。界面采用 Adafruit 内置字体的英文提示，无需额外字体资源。

屏幕参考主固件的 30 像素黑色圆角遮罩，包含电量指示、圆角内容卡片、录音状态和操作提示。电量计不可用时显示 `--`，不阻止录音；录音和回放期间暂停电量轮询。音频期间只重绘较小的进度区域，每次处理 10 毫秒 PCM 后轮询按键。

## 实机验收

说话录制约 3 秒，松开 OK，再按 UP 回放。确认人声可辨识，无明显杂音、失真或中断。还应测试短按、按住超过 3 秒、再次录音、停止回放和清除；核对音频时长与实际时间，并检查削波计数和采集错误。编译通过、麦克风非零数据或测试音可听，均不能代替人声录音质量验收。

已完成检查见[验证记录](validation.zh_CN.md)；此示例的实机录音/回放验收应单独记录。

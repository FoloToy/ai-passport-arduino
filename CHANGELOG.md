## 0.1.0 — 2026-10-07

Initial Arduino implementation for the ESP32-C3 AI Passport: display/backlight,
polled button events, ES8311 mono PCM audio, read-only CW2017 readings, and seven
example sketches. Includes standard Arduino metadata, protected example partition
layouts, English/Chinese documentation, host tests, and CI.

This is an early implementation, not a hardware-accepted stable release.
See `docs/validation.md` for the exact verification status.
